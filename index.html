Extract subtitle from MKV MKVToolNix

Install MKVToolNix automatically or set its location once. The app saves it locally and checks it at every launch. Then select an MKV and load a subtitle track as reference or target, or download it as an SRT without loading it. The video remains on your computer; extraction is local.

Sync method

Uses the reference subtitle for automatic re-sync or the manual timing controls below. The selected video is not used in this mode.

Automatic sync to video ffsubsync

Uses the video audio's speech/silence pattern to align the loaded target SRT. This is language-independent, runs locally, and creates a corrected copy for preview. Select the MKV first, then load or extract the target subtitle. The automatic installer downloads Python, ffsubsync, and FFmpeg once; syncing itself stays local.

Reference subtitle manual sync

Load a correctly timed reference subtitle here. The local multilingual model matches the meaning of the English and Hungarian lines, then aligns their timing. Your files stay on this computer.

4. Gradual timing correction optional · linear drift

If timing is correct at the beginning but drifts by the end, choose two matching scenes. The app gradually adjusts timing between the first and last anchor, and continues with the same rate outside them.

Time format: HH:MM:SS,mmm or seconds (for example 312.5). The global offset is applied as well.
